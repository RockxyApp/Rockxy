# Rockxy Community and Pro

Rockxy uses two related distribution artifacts:

- The **public Community source edition** is the source in the Rockxy GitHub
  repository. It is available under AGPL-3.0-or-later and builds with
  `DefaultAppPolicy`.
- The **official signed Rockxy app** is built from a separate downstream
  distribution. The same installed app runs in Community mode without a
  purchase and unlocks Pro when an eligible license is active. The official
  binary is governed by the [Rockxy Binary EULA](https://github.com/RockxyApp/Rockxy/blob/main/legal/BINARY-EULA-v1.0.md).

The public repository is not the complete or exact source tree used to build
the official DMG. See [Rockxy Licensing](https://github.com/RockxyApp/Rockxy/blob/main/LICENSING.md) for the
artifact-by-artifact boundary.

## Community source edition

The public source edition includes the complete local-first debugging baseline:

- HTTP, HTTPS, WebSocket, and GraphQL capture;
- request replay and editing;
- Map Local, Map Remote, Block, Modify Headers, Network Conditions, and
  Breakpoints;
- Compare, scripting, sessions, and HAR import/export;
- Developer Setup Hub guidance and supported one-shot setup workflows; and
- the local MCP server and bridge, including rule and capture changes once you
  allow them in **Settings → MCP**.

The source edition applies the capacity policy defined by `DefaultAppPolicy`,
including limits for workspaces, favorites, rules, scripts, live history,
Developer Setup profiles, and selected advanced workflows.

## Community mode in the official app

The official signed app starts in Community mode and can be used without a
purchase. Community mode is a runtime entitlement state inside that binary; it
does not mean the complete official binary is published under the AGPL or built
solely from the public repository.

## Pro in the official app

An eligible Pro license lifts supported capacity limits and enables paid
workflow depth in the official app. The exact capabilities depend on the
installed version and entitlement. The app shows the authoritative current
state in **Rockxy → Settings → License** and at the action boundary for a paid
workflow.

Feature names in a roadmap or source-level flag are not proof that a complete
workflow ships. Public documentation describes a Pro capability as available
only when the official app contains its implementation and user-facing path.

## Licensing summary

| Item | Terms |
| --- | --- |
| Public Community source and builds made solely from it | AGPL-3.0-or-later |
| Official signed app, including Community mode | Rockxy Binary EULA |
| Pro entitlement | Binary EULA plus applicable purchase terms |
| Third-party components | Their respective licenses |
