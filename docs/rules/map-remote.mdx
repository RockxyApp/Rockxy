# Map Remote

Map Remote rewrites where a request goes without requiring the original client to change its configured base URL.

## Use Map Remote when

- you want production-shaped traffic to hit staging,
- you need to send one endpoint to a local development server,
- you are testing a new API version behind the same client,
- or you need to redirect a CDN or service dependency temporarily.

## Common patterns

### Swap only the host

Useful when the path and query are already correct but the environment is wrong.

### Swap the path

Useful when you want to test a new route while keeping the same host and authentication context.

### Swap protocol or port

Useful when you are sending traffic to a local service or test environment with a different transport shape.

### Redirect one GraphQL operation

Set **GraphQL Operation** to send only that operation (for example `GetUsers`) to another
server while every other operation on the same endpoint keeps its original destination. Rules
created from a captured GraphQL request prefill the operation name.

## Organize rules in folders

Group related rules into folders. Select rules and choose **New Folder with Selection** from the context menu or the **More** menu, or drag rules onto a folder. The folder's checkbox turns every rule inside it on or off (mixed when only some are on), and the active-rule limit still applies. **Rename Folder…** and **Delete Folder** are on the folder's context menu; deleting a folder keeps its rules. Folders only organize the list — rules keep their first-match order — and searching lists matches without folders.

## Practical advice

Start with the smallest rewrite that proves the behavior change you want. If changing only the host works, do not rewrite path and query too.
